חשוב לפני כל עדכון: באפליקציה הנוכחית ללכת ל"עוד" > "גיבוי ושחזור" > "יצירת גיבוי", להעתיק את הטקסט ולשמור (או לשלוח לטלגרם).
הגרסה הזו נחתמת במפתח קבוע (app/debug.keystore) ולכן כל עדכון עתידי יותקן מעל הקיים ולא ימחק נתונים.
אם הגרסה שמותקנת אצלך כרגע נחתמה במפתח אחר, אנדרואיד יסרב לעדכן: אז מסירים, מתקינים, ומשחזרים מהגיבוי (עוד > שחזור מהטקסט).
בנוסף האפליקציה שומרת עותק של הנתונים בתיקייה הפנימית שלה, ומשחזרת ממנו אם נתוני הדפדפן הפנימי נעלמו.

בנייה (במחשב):
1. להתקין Android Studio (גרסה עדכנית) ולבחור Open על התיקייה FamilyManager.
2. לחכות לסיום Gradle Sync (דורש אינטרנט בפעם הראשונה).
3. Build > Build Bundle(s) / APK(s) > Build APK(s). הקובץ: app/build/outputs/apk/debug/app-debug.apk
4. להעביר לטלפון ולהתקין (לאשר התקנה ממקור לא ידוע).

אחרי ההתקנה:
- לאשר הרשאת התראות והודעות SMS.
- יפתח מסך "גישה להתראות": להפעיל את האפליקציה.
- באנדרואיד 13+ אם ההפעלה חסומה: הגדרות > אפליקציות > ניהול עסק וכספים > ⋮ > אפשר הגדרות מוגבלות.
- תזכורת הוצאת מרשם יומית ב-10:00 נשלחת מהאפליקציה עצמה (גם כשהיא סגורה).
- נתוני הדפדפן לא עוברים: להשתמש בגיבוי ושחזור (מסך הבית).

בנייה בלי להתקין כלום (דרך GitHub):
1. ליצור repository פרטי ב-GitHub ולהעלות אליו את כל תוכן התיקייה (כולל .github).
2. ללשונית Actions > Build APK > Run workflow (או פשוט לחכות אחרי ה-push).
3. בסיום להוריד מה-Artifacts את FamilyManager-apk ולהתקין בטלפון.
